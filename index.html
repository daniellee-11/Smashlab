    动作技术要点速查

    基于 MediaPipe Pose + TensorFlow.js LSTM · 全部推理在本地浏览器完成，视频不上传服务器

    打包为手机/桌面 App

    本应用是纯前端（HTML/CSS/JS），可一键套壳发布到 iOS / Android / 桌面。

    ✅ 已为你生成原生工程

    • Android 工程：android/（Android Studio 打开 android/）
    • iOS 工程：ios/（Xcode 打开 ios/App/App.xcworkspace）
    • 相机权限已自动配置：Android CAMERA 权限、iOS NSCameraUsageDescription

    方案 A：Capacitor（推荐，已生成）

    # 1) 联网构建离线资源（含姿态模型 .task）
npm run build
# 2) 同步到原生工程并打相机权限补丁
npm run make:android   # 生成/更新安卓
npm run make:ios       # 生成/更新 iOS
# 3) 打开 IDE 运行或打包
npx cap open android   # Android Studio
npx cap open ios       # Xcode（macOS）

    方案 B：Tauri（更小、更快、Rust 内核）

    npm i @tauri-apps/cli
npx tauri init        # devUrl=http://localhost:8080, distDir=./dist, 前端类型=无框架
npx tauri build       # 产出原生安装包

    关键适配点

    • 摄像头权限已在原生配置里声明（AndroidManifest 的 CAMERA / iOS Info.plist 的相机用途说明），原生 WebView 内 getUserMedia 可直接用。
    • 已内置离线支持：npm run build 会把 MediaPipe wasm、tfjs、jsPDF 全部下载进 dist/；姿态模型 pose_landmarker_lite.task 需联网下载一次（自动放入 dist/models/）。
    • 球场弱网环境：用 dist/ 打包，启动即本地加载全部模型，无需联网。
    • MediaPipe 在部分手机 WebView 的 GPU 加速不可用，App 已自动回退到 CPU delegate。
